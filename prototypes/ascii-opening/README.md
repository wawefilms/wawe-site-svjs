## Global grid and logo motion

**Global Cell Px** sets both logo and water to the same character size and spacing: horizontal spacing `cell`, vertical spacing `cell × 1.18`, font size `cell × 1.4`. There is no hidden finer logo grid or adaptive cell cap.

Logo → Motion compares:

- **Flowing texture** (`logoMotion=flow`, default): slow diagonal/upward character drift through the fixed artwork mask, plus gentle glyph substitution. Sampling phase changes over time without moving the silhouette.
- **Fixed grid / changing glyphs** (`logoMotion=glyphs`): character centres remain fixed; shapes and intensity evolve with coherent noise.

The artwork mask selects character centres, as in the earlier logo rendering. Every selected glyph is drawn whole—no silhouette clipping or sliced characters at the edges. Cached grayscale samples are rebuilt only when artwork/size changes. This intentionally allows a glyph to extend slightly across an artwork boundary.

Both motion modes use the entire selected character palette, with per-cell phases and slow changes rather than concentrating choices in the middle of the ramp. The ASCII palette includes punctuation, marks and denser symbols: `.,:;~=+*oO#@`. No solid logo is drawn underneath.

Motion can help the coarse grid read over time but cannot guarantee the clarity of a finer grid. Judge both modes at the same global size, including on a phone.

Old `logoCell=` is ignored. `cell=` is now the sole global size; changing a control or copying a settings link removes the obsolete parameter. Old `churn=` is also ignored: it represented glyph substitution, not fluid turbulence.

## Shared vocabulary / DialKit

| Control | Meaning |
| --- | --- |
| Treatment | Dark/off-white, light/WAWE-blue, or brand-dark/navy + blue |
| Logo Mask | Artwork silhouette occupied by characters |
| Glyph Palette | ASCII, mixed, or Unicode stipple; “ASCII” may describe the overall technique loosely |
| Mono Font | Plex, Geist, or platform monospace |
| Global Cell Px | Literal shared grid spacing, 2–20 CSS px |
| Logo Height | Percentage of viewport height, constrained to fit screen width |
| Motion | Flowing logo texture or fixed-grid glyph changes |
| Reach | Maximum foam travel as a percentage of the logo-to-bottom gap |
| Fill Density | Fraction of candidate water cells kept, not opacity |
| Fade Start Percent | Fade begins this far along the bottom→reach journey. 75 means fade through the final quarter. Local onset undulates around the average. |
| Crest Width Percent | Leading band's overall thickness, 50–150%; separate from wake spread |
| Thickness Variation | Lower gives a more even crest cross-section; 100 restores the earlier folding/noisy shape. Does not fill holes caused by low density. |
| Travel Speed | Shared simulation clock multiplier; changing it does not reset phase |
| Coast Relief | Broad shoreline undulations, limited by available water depth |
| Foam Turbulence | Spatial distortion, small eddies and fragmentation, not per-frame random flashing |
| Foam Spread | Width of the wake behind the crest |
| Foam Persistence | How long deposited foam survives |
| Offshore Texture | Continuing water texture below the breaker |
| Ink Strength | Water character opacity |

Reach geometry:

```text
reachY = viewportHeight - (viewportHeight - logoBottom) × reach / 100
fadeStartY = viewportHeight - (viewportHeight - reachY) × fadeStart / 100
```

0% reach gives no water; 100% permits foam to approach the logo bottom. Changing logo size/mask recomputes the gap. The overhead reference describes water behaviour, not a newly approved half-screen water layout.

The water renderer combines one advancing breaker, offshore texture and recent foam deposits into a field sampled by glyphs. Domain-warped coherent noise creates lace and motion. The front continues through the dissipation band instead of parking at its limit; both cell coverage and opacity fade away. This is a **procedural approximation, not a fluid simulation**.

## End-wave glow fix

With the reported composition, a new residue deposit was being **added** to the still-visible breaker late in its travel. Both increased foam coverage and cream-highlight mapping produced a second brightness peak.

Residue now replaces overlapping active foam (`max`, not addition). Only the active breaker receives cream highlights; old foam remains blue in brand-dark. This retains a lingering wake without a late cream flash.

The deterministic probe runs the actual `drawWater` implementation against a measuring canvas:

```sh
node prototypes/ascii-opening/measure-water.mjs
# Expected PASS: no late-wave brightness rebound above 2% in the reported composition.

node prototypes/ascii-opening/measure-water.mjs --before-fix
# Expected failure: reinstates only the former two blend expressions in memory.
```

This measures summed glyph ink luminance × alpha, **not rasterised glyph pixel area**. It is a narrow regression signal for the reported viewport/settings, not proof that all parameter combinations are perceptually monotonic. Browser playback remains the visual check.

## Review tools and accessibility

- **Paused** freezes both water and logo texture.
- **Composition Guides** marks logo bottom, maximum reach and average fade start. The actual fade onset is irregular.
- **Copy settings link** shares the URL; pause first to preserve time. DialKit's built-in clipboard action copies parameters, not the page URL.
- **Reset study** restores the latest baseline and time, retaining pause/guide choices.
- Settings live in the URL and memory only, not localStorage.
- Reduced motion starts with **both canvases paused**. Explicit unpause is available for review. Production must skip to the settled showreel, which intentionally does not exist here.
- Hidden tabs stop rendering and resume without advancing through hidden time.
